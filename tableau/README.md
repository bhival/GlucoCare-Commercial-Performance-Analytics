# Tableau Dashboard — GlucoCare Commercial Performance

This folder holds the packaged Tableau workbook (`.twbx`). Export it from Tableau
Desktop (File → Export Packaged Workbook) and place it here as:

```
tableau/glucocare_commercial_performance.twbx
```

## Dashboard Structure

| Zone | Contents |
|---|---|
| Header | Filters for territory, region, month, specialty |
| KPI Row | Market Share %, Revenue (Cr), Calls per Doctor, Price Gap % |
| Main Charts | Market Share Trend (line), Territory Ranking (bar) |
| Diagnostics | Doctor Segments (bar), Rep Effectiveness (scatter) |

## Viewing Without Tableau Desktop

- Tableau Public (free) — open and publish `.twbx` files for a shareable link
- Tableau Reader (free) — open `.twbx` files locally
